# GSK改造项目作品集

专业的工业自动化改造项目作品集网站。

## 技术栈

- React 18 + TypeScript
- Vite 6
- TailwindCSS 3
- Lucide React Icons

## 功能特性

- 📱 响应式设计
- 🖼️ 图片画廊
- 🎬 视频播放
- 📄 文档下载

## 开发

```bash
npm install
npm run dev
```

## 部署

项目已配置 Vercel 部署，可直接在 Vercel 上一键部署。

## 项目结构

```
src/
├── components/   # 组件
├── pages/        # 页面
├── App.tsx       # 主应用
└── index.css     # 样式
```
